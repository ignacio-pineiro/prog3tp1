# Proyecto: Match Play

## Descripcion
Hicimos una aplicación para ver información del mundial 2026
- Partidos
- Grupos
- Selecciones

## API Utilizada
Utilizamos la [API SportsAPI Pro](https://sportsapipro.com/) que trae toda la información del mundial
